Classification Logic

Each vendor is classified by the number of distinct P&L expense heads its spend is booked under. Balance-sheet routing (Accounts Payable, Bank, GST/TDS clearing, Vendor Advances) is excluded so classification reflects genuine spend behaviour.

Definitions

Fixed ExpenseConsistently booked under the same expense head every month. Predictable, low-risk coding.
